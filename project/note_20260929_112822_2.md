#  urgently needed: Please provide your Git repository URL and authentication method

To safely and correctly clone your repository, I require exactly two pieces of information:

1. ✅ Repository URL — e.g.,
   • HTTPS: https://github.com/username/repo.git
   • SSH: git@github.com:username/repo.git

2. ✅ Authentication method — choose ONE and provide required credential:
   • 🔑 SSH Key: Ensure ~/.ssh/id_rsa exists & is added to ssh-agent (no token needed)
   • 🪙 Personal Access Token (PAT): A fine-grained or classic token with 'repo' scope (for HTTPS URLs)
   • ❌ Password: Not supported since Aug 2021 (GitHub policy)

⚠️ Without these, no git clone can proceed — all tools are currently blocked by missing inputs and empty knowledge base.

I will immediately resume full debugging & cloning workflow upon receipt.
