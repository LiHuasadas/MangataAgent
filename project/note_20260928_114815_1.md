# 冒泡排序基线实现 —— 生产级规范

【目标】
提供一份符合 PEP 8、类型提示（PEP 484）、防御性编程、可测试性与可维护性的冒泡排序参考实现。

【核心要求】
- ✅ 纯函数式：不修改输入列表，返回新排序列表；
- ✅ 类型安全：完整 `typing.List`, `typing.Union`, `typing.TypeVar` 注解；
- ✅ 异常防御：对非列表输入、不可比较元素提供清晰错误信息；
- ✅ 性能优化：提前终止（无交换即退出），时间复杂度最坏 O(n²)，最好 O(n)；
- ✅ 边界鲁棒：空列表、单元素、全等元素、逆序、含 None/NaN 等场景显式处理；
- ✅ 可测试：内置 `if __name__ == "__main__":` 测试套件，覆盖全部典型用例；
- ✅ 可执行：生成**语法合法、无 shell 转义污染、UTF-8 编码、无 BOM 的纯文本 Python 文件**；
- ❌ 不依赖 `echo` 重定向生成（已验证其在 Windows CMD 下对多行/引号/f-string 失效）；

【交付物】
- 完整、自包含、可直接保存为 `bubble_sort.py` 并运行的源码；
- 源码中所有字符串均使用原始字符串（`r"..."`）或双引号+转义规避 CMD 解析风险（如需人工粘贴）；
- 提供等效的、**完全规避 shell 解析的 Python 动态写入方案**（用于自动化环境）；

【验证方式】
- `python -m py_compile bubble_sort.py` → 零错误；
- `python bubble_sort.py` → 输出明确测试结果；
- `mypy bubble_sort.py` → 类型检查通过（若安装 mypy）；
