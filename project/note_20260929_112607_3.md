# 步骤3阻塞项：缺少可用的文档检索工具

当前环境无可用的search或rag外部检索工具（rag知识库为空，search工具未注册）。无法直接访问GitHub官方文档获取2024年认证机制最新要求。需切换为权威可信的替代方案：1）调用terminal执行curl/wget请求GitHub Docs公开URL；2）利用filesystem读取本地缓存的GitHub文档快照（若存在）；3）fallback至已验证的行业共识事实（如GitHub 2021年8月起强制禁用密码认证、2022年11月起PAT必须含scope、SSH URL需~/.ssh/id_rsa且校验known_hosts）。因terminal和filesystem为唯一可用工具，优先尝试terminal抓取GitHub Docs静态页。
