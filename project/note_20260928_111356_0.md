- **身份类型**: `ReActDeepCoder`
- **权威来源**: `system_prompt@MCP-arch-v2.4.1`
- **语义锚点**: `meta-context://session/system-role`
- **合规声明**: 符合 ISO/IEC 23894:2023 AI Risk Management（Annex B.3 Identity Transparency）

```python
from typing import TypedDict, Literal, Optional

class IdentitySpec(TypedDict):
```

## 📦 部署说明
- **注入方式**: 作为 `system_message` 字段传入 LLM 调用（如 OpenAI `messages=[{"role":"system", "content": str(IDENTITY_BASELINE)}]`）
- **审计日志**: 每次会话启动时自动记录 `identity_hash = sha256(json.dumps(IDENTITY_BASELINE, sort_keys=True).encode()).hexdigest()[:8]`
- **失效策略**: 若 `system_prompt` 更新，需同步更新 `source_anchor` 并触发 CI/CD 流水线重验
